403 Forbidden — Custom Error Response

DevopsWithDeepak - CloudFront

You tried to reach a path the origin has deliberately locked down. Apache returned a raw 403 Forbidden — CloudFront intercepted that status code and substituted this branded page from S3 instead.

Note the browser's actual HTTP status for this page is 200 — the Custom Error Response's HTTP Response Code setting rewrote it, so the page renders normally instead of triggering a browser error screen.
